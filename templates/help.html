❓ Help & Documentation

Complete guide to using the Tool Version Audit & Notification System.

🚀 Quick Start Guide

  1. Submit Your Tools: Go to the Submit page and enter your tool information
  2. Monitor Status: Check the Dashboard to see update status
  3. Receive Notifications: Get email alerts when updates are available
  4. Follow Instructions: Use provided upgrade steps to update your tools

🤔 Frequently Asked Questions

How does the system work?

Our system automatically checks for the latest versions of your submitted tools by querying official sources like GitHub releases and vendor websites. When a newer version is detected, we send you an email notification with upgrade instructions.

How often are version checks performed?

Version checks are performed daily at 9:00 AM. You can also manually trigger a check for specific tools using the "Check Now" button on the dashboard.

What tools are supported?

We support major development tools including:

  • SQL Server, Oracle Database, MySQL, PostgreSQL
  • Python, Node.js, Java, .NET Framework
  • Visual Studio, Docker, Kubernetes, Git
  • Many more... If your tool isn't listed, select "Other" when submitting

How do I format version numbers?

Version numbers should include at least one number. Examples:

  • SQL Server 2019
  • Python 3.9.1 or 3.9.1
  • Node.js 14.2.0 or v14.2.0
  • Java 11 or JDK 11

Can I update my submitted information?

Currently, you need to submit a new entry if your version changes. We're working on an update feature for future releases.

What if I don't receive email notifications?

Check your spam folder first. If you still don't receive emails, contact your administrator to verify the email configuration. You can also check the dashboard regularly for status updates.

📧 Email Configuration

For administrators setting up the system, configure these environment variables:

export SMTP_SERVER="smtp.gmail.com"
export SMTP_PORT="587"
export SENDER_EMAIL="your-email@company.com"
export SENDER_PASSWORD="your-app-password"
export SENDER_NAME="Tool Version Monitor"

Note: For Gmail, use an App Password instead of your regular password. Enable 2-factor authentication and generate an app-specific password.

🔧 Troubleshooting

Version Check Fails

  • Ensure internet connectivity for external API calls
  • Check if the tool has a configured version source
  • Some tools may have rate limits on their APIs

Email Not Sending

  • Verify SMTP configuration in environment variables
  • Check firewall settings for SMTP port (usually 587)
  • Ensure sender email has proper authentication
  • Test email configuration using the Admin Panel

Database Issues

  • Ensure the data/ directory has write permissions
  • Check disk space availability
  • SQLite database is created automatically on first run

🔌 API Endpoints

The system provides these API endpoints for integration:

POST /api/check-version

{"submission_id": 123}

POST /api/send-test-email

Send a test email to verify email configuration.

{"email": "test@example.com"}

💻 Command Line Usage

The daily check script can be run manually with different options:

# Run version check immediately
python daily_check.py run
# Check for missed notifications
python daily_check.py notify
# Run as scheduled service
python daily_check.py schedule
# Test mode (first 3 submissions only)
python daily_check.py test

Cron Setup: To run daily checks automatically, add this to your crontab:

0 9 * * * /usr/bin/python3 /path/to/daily_check.py run
